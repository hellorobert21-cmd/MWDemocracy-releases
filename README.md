# MWDemocracy releases

Official releases of **MWDemocracy**, a school election system.

- **`kits/`**: school install kits (`mwdemocracy-school-kit-<version>.zip`).
  Unzip on your server and run `sudo ./deploy/install.sh --license license.txt`.
  The kit's `README.md` explains everything.
- **`latest.txt`**: the signed release file that every MWDemocracy server
  checks for updates. Servers accept it only if it is signed with the
  vendor's release key.

To get a license or support, contact the vendor.
